
Source Code Overview

This directory contains all source code used in the study
"Quantum Algorithms for Disaster Prediction and Management".

File descriptions:

- cleaning.py
  Performs preprocessing and cleaning of the raw EM-DAT dataset.

- ai_model.py
  Implements the classical AI and machine learning components.

- quantum_qbm.py
  Quantum Boltzmann Machine simulation for disaster classification.

- quantum_qaoa.py
  Quantum Approximate Optimization Algorithm for resource allocation.

- quantum_qpe.py
  Quantum Phase Estimation for disaster severity simulation.

- quantum_walk.py
  Quantum walk-based evacuation route optimization.

- analysis_validation.py
  Validation routines including VIF analysis and ablation studies.

- main.py
  Entry point for running the full experimental pipeline.
