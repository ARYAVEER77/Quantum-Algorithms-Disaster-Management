## Data Availability

The raw datasets used in this study are publicly available and stored in the repository under:

📁 `data/raw/`

This includes:
- `emdat_1970_2021.csv` — processed disaster event data derived from EM-DAT
- Source EM-DAT Excel files converted to CSV for reproducibility

Detailed dataset descriptions, provenance, and preprocessing notes are provided in:

➡️ [`data/raw/README.md`](data/raw/README.md)

All datasets are used strictly for academic research purposes.
